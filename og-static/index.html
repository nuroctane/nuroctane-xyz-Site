This Vercel deployment exists only to serve /api/og, the dynamic Open Graph card renderer. It is not the website.

The site itself runs on Cloudflare Workers and proxies /api/og here, so crawler meta tags keep pointing at www.nuroctane.xyz.

The card renderer stayed on Vercel because it uses Satori + resvg, which needs more CPU per invocation than the Cloudflare Workers free plan allows (10 ms). Moving it means enabling Workers Paid and swapping @vercel/og for workers-og.
