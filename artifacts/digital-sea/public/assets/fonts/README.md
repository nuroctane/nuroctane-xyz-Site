# Display fonts

These fonts are self-hosted for the Digital Sea theme.

| File               | Family       | Source                                   | License note         |
| ------------------ | ------------ | ---------------------------------------- | -------------------- |
| `sprite-coder.ttf` | Sprite Coder | https://www.dafont.com/sprite-coder.font | 100% Free            |
| `technoid.ttf`     | Technoid     | https://www.dafont.com/technoid.font     | Freeware / 100% Free |
| `alarm-clock.ttf`  | Alarm Clock  | https://www.dafont.com/alarm-clock.font  | 100% Free            |
| `jet-set.ttf`      | Jet Set      | https://www.dafont.com/jet-set.font      | 100% Free            |

The hero stack prefers locally installed `Adobe Hebrew`. Adobe Fonts requires a
site-specific Web Project kit and does not permit copying its hosted web files
into this repository, so the public fallback is Cormorant Garamond.
